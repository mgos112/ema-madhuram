# accordion

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table. One row per item, two cells: question (plain text) | answer (rich text). Rows without a question are dropped; a missing answer cell renders an empty body. Write the question in its normal case; the divider option uppercases it in CSS. Name the block `Accordion (Divider)` to apply the divider option.

## Supported variations

| Variation | Option class |
| --- | --- |
| Divider | `divider` |
