# tabs

Custom **tabs** block. Purpose: tabbed panels with an ARIA tablist (role=tab/tabpanel, aria-selected, arrow/Home/End key navigation); the first tab is active.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: cell 1 = tab label (plain text), cell 2 = panel rich text (paragraphs, H2/H3, images, lists); a label with no content keeps an empty panel, extra cells merge into the panel, fully empty rows are dropped.
