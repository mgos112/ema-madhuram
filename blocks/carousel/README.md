# carousel

Custom **carousel** block. Purpose: image (and optional text) slides with prev/next buttons and dot indicators below the slides, keyboard accessible (left/right arrow keys when the carousel has focus).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = image, optional cell 2 = slide content (dropped when empty, extra cells merged into it); empty rows are skipped.
